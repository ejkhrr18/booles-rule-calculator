What is Boole's Rule?

Boole's Rule (also called Bode's Rule) is a numerical integration technique belonging to the family of closed Newton–Cotes formulas. It approximates the definite integral of a function \( f(x) \) over an interval \([a,\, b]\) by fitting a fourth-degree polynomial through five equally spaced sample points and integrating that polynomial exactly.

Given an interval \([a, b]\), the rule divides it into four equal subintervals of width \( h = \tfrac{b-a}{4} \), producing five nodes:

\[ x_0 = a,\quad x_1 = a+h,\quad x_2 = a+2h,\quad x_3 = a+3h,\quad x_4 = b \]

The integral is then approximated by the weighted sum:

\[ \int_a^b f(x)\,dx \;\approx\; \frac{2h}{45} \Bigl(7f(x_0) + 32f(x_1) + 12f(x_2) + 32f(x_3) + 7f(x_4)\Bigr) \]

The coefficients 7, 32, 12, 32, 7 arise from integrating the Lagrange interpolating polynomial through the five nodes. Note the symmetry of the weights — the outer nodes carry a factor of 7, the inner edge nodes 32, and the midpoint 12.

Boole's Rule is exact for polynomials of degree ≤ 5, even though it is derived from a degree-4 polynomial fit. The truncation error over a single application is:

\[ E = -\frac{8}{945}h^7 f^{(6)}(\xi), \quad \xi \in (a,\, b) \]

This sixth-derivative dependence means the rule converges rapidly for smooth functions but may lose accuracy when \( f \) has large higher-order derivatives.

Order of Accuracy
Exact for polynomials of degree \(\leq 5\)
Number of Nodes
5 equally spaced points \((n = 4)\)
Weights
\(\tfrac{2h}{45}(7,\,32,\,12,\,32,\,7)\)
Truncation Error
\(O(h^7 f^{(6)})\)

Worked Example 1

Integrate \( f(x) = x^4 \) over \([0,\,2]\)

The exact value is \(\displaystyle\int_0^2 x^4\,dx = \left[\tfrac{x^5}{5}\right]_0^2 = \tfrac{32}{5} = 6.4\). Since \(f(x)=x^4\) is a degree-4 polynomial, Boole's Rule should be exact.

  1. Compute the step size \(h\).
    \[ h = \frac{b - a}{4} = \frac{2 - 0}{4} = 0.5 \]
  2. Find the five nodes.
    \[ x_0 = 0,\quad x_1 = 0.5,\quad x_2 = 1.0,\quad x_3 = 1.5,\quad x_4 = 2.0 \]
  3. Evaluate \(f(x) = x^4\) at each node.
    \[ f(x_0)=0,\quad f(x_1)=0.0625,\quad f(x_2)=1,\quad f(x_3)=5.0625,\quad f(x_4)=16 \]
  4. Apply the weighted sum.
    \[ S = 7(0) + 32(0.0625) + 12(1) + 32(5.0625) + 7(16) = 0 + 2 + 12 + 162 + 112 = 288 \]
  5. Multiply by the leading factor \(\tfrac{2h}{45}\).
    \[ \int_0^2 x^4\,dx \;\approx\; \frac{2(0.5)}{45} \times 288 = \frac{1}{45} \times 288 = 6.4 \]
    ✓ Result: 6.4000  |  Exact value: 6.4  |  Error: 0.0000
example_02.py
Worked Example 2

Integrate \( f(x) = \sin(x) \) over \([0,\,\pi]\)

The exact value is \(\displaystyle\int_0^{\pi}\sin(x)\,dx = [-\cos x]_0^{\pi} = 2\). Since \(\sin(x)\) is not a polynomial, there will be a small truncation error.

  1. Compute the step size \(h\).
    \[ h = \frac{\pi - 0}{4} = \frac{\pi}{4} \approx 0.7854 \]
  2. Find the five nodes.
    \[ x_0 = 0,\quad x_1 = \tfrac{\pi}{4},\quad x_2 = \tfrac{\pi}{2},\quad x_3 = \tfrac{3\pi}{4},\quad x_4 = \pi \]
  3. Evaluate \(\sin(x)\) at each node.
    \[ f(x_0)=0,\quad f(x_1)=\tfrac{\sqrt{2}}{2}\approx0.7071,\quad f(x_2)=1,\quad f(x_3)\approx0.7071,\quad f(x_4)=0 \]
  4. Apply the weighted sum.
    \[ S = 7(0) + 32(0.7071) + 12(1) + 32(0.7071) + 7(0) = 0 + 22.627 + 12 + 22.627 + 0 = 57.254 \]
  5. Multiply by \(\tfrac{2h}{45}\).
    \[ \int_0^{\pi}\sin(x)\,dx \;\approx\; \frac{2 \times 0.7854}{45} \times 57.254 = 0.03491 \times 57.254 \approx 1.9998 \]
    ✓ Result: 1.9998  |  Exact value: 2.0000  |  Error: 0.0002
